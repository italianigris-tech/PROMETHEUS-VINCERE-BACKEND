# Mini-Run Generative Typography Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace phrase-specific mini-run typography treatment with a prompt-configurable generative selector driven by the complete portrait font and supported Anima typography catalogs.

**Architecture:** The Python mini-run selector resolves a normalized design policy, scores font profiles and runtime-supported animation families, and writes evidence into the existing font manifest. The Remotion composition consumes the selected primary effect, overlay, and timing fields. Modal stays a transport layer because it packages the same pipeline and composition.

**Tech Stack:** Python 3.9, unittest, TypeScript, React, Remotion, Modal.

## Global Constraints

- Scope is restricted to mini-run paths; do not modify macro or landscape systems.
- No phrase-specific, token-specific, or profile-ID-specific treatment selection.
- All portrait profiles returned by `load_all_portrait_font_json_profiles()` remain eligible.
- Render only through `prometheus-mini-run-studio` using `--gl swangle`.
